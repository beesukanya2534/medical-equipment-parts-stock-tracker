# Medical Equipment Parts Stock Tracker

เว็บแอปบันทึกคลังอะไหล่เครื่องมือแพทย์ ใช้เติม ตัดจ่าย ตรวจนับ และดูยอดคงเหลือ

## ความสามารถ

- **คงคลัง:** ดูยอดคงเหลือ รับรวม และจ่ายรวม แยกตามหมวด พร้อมสถานะ ปกติ / ใกล้หมด / หมด
- **เติม / ตัดจ่าย / ตรวจนับ:** บันทึกจำนวน หน่วยงานหรือวอร์ด วันเวลา และหมายเหตุ ระบบไม่ให้ตัดจ่ายเกินยอดที่มี
- **เตือนจัดซื้อ:** รายการที่เหลือต่ำกว่า 5 ชิ้นจะกระพริบเตือนให้จัดซื้อเติม
- **บัตรคุมวัสดุ:** ประวัติรับ จ่าย และคงเหลือสะสมของแต่ละรายการ
- **ประวัติ:** กรองตามรายการ ประเภท และช่วงวันที่ ลบรายการที่บันทึกผิดได้
- **ส่งออก CSV:** ส่งออกยอดคงคลังและประวัติไปเปิดใน Excel
- **เพิ่มรายการ:** เพิ่มอะไหล่ใหม่ได้ ระบบตั้งลำดับถัดไปให้เอง

## รายการตั้งต้น

| เปิดจาก | ข้อมูลเก็บที่ | ใช้ร่วมกันหลายคน |
| --- | --- | --- |
| GitHub Pages | Supabase (ต้องเข้าสู่ระบบ) | ได้ อัปเดตสดทุกเครื่อง |

สองที่นี้เก็บข้อมูลแยกกัน ถ้าจะย้ายข้อมูลข้ามกัน ให้กด **สำรองข้อมูล** ฝั่งหนึ่ง แล้วกด **นำเข้าไฟล์สำรอง** อีกฝั่ง

## Supabase

- **Project:** `medical-equipment-parts-stock` (ภูมิภาค ap-southeast-1 สิงคโปร์)
- **โครงสร้างตาราง:** [supabase/schema.sql](supabase/schema.sql) ประกอบด้วย `items` (รายการอะไหล่), `txns` (ประวัติเติม ตัดจ่าย ตรวจนับ) และ `staff` (อีเมลที่มีสิทธิ์ใช้งาน)
- **ความปลอดภัย:** เปิด Row Level Security ไว้ ทั้งดูและบันทึกต้องเข้าสู่ระบบ และอีเมลต้องอยู่ในตาราง `staff` คนที่ไม่ได้เข้าสู่ระบบอ่านข้อมูลไม่ได้เลย ถึงจะมี key ในหน้าเว็บก็ตาม
- **ลบรายการอะไหล่:** ลบไม่ได้ ใช้วิธีซ่อนแทน ประวัติจึงอยู่ครบเสมอ

### เพิ่มเจ้าหน้าที่

1. ที่ Supabase Dashboard ไปที่ **Authentication → Users → Add user → Create new user** ใส่อีเมลและรหัสผ่าน แล้วติ๊ก Auto Confirm
2. ไปที่ **Table Editor → staff → Insert row** แล้วใส่อีเมลเดียวกันเป็นตัวพิมพ์เล็ก

### กันโปรเจคหยุดทำงาน

Supabase แบบฟรีจะหยุด project ชั่วคราวถ้าไม่มีการใช้งานประมาณ 1 สัปดาห์ GitHub Action [keep-alive.yml](.github/workflows/keep-alive.yml) จึงส่ง ping ทุก 3 วัน ping นี้อัปเดตแค่ตาราง `heartbeat` ไม่แตะข้อมูลคลัง ประวัติจึงไม่มีรายการปลอม ถ้าจะสั่งรันเองให้ไปที่แท็บ **Actions → Keep Supabase awake → Run workflow**

แนะนำให้ปิดการสมัครสมาชิกเองที่ **Authentication → Sign In / Providers → Allow new users to sign up** ถึงจะไม่ปิด คนที่สมัครเองก็ยังเข้าถึงข้อมูลไม่ได้ ถ้าอีเมลไม่อยู่ในตาราง `staff`

### โครงสร้างข้อมูล

- `items/{id}`: `no`, `name`, `category`, `unit`, `min` (จุดสั่งซื้อ), `archived`, `createdAt`
- `txns/{id}`: `itemId`, `type` (`in` = เติม, `out` = ตัดจ่าย, `adj` = ปรับยอดตรวจนับ), `qty`, `counted`, `ward`, `note`, `by`, `at`, `createdAt`

ยอดคงเหลือคำนวณจากผลรวมของ `txns` ทุกรายการ จึงไม่มีปัญหายอดเพี้ยนเมื่อหลายคนบันทึกพร้อมกัน
